¿Qué hará el reconocimiento automático?

El siguiente paso será convertir las notas de una fotografía o PDF en una partitura editable (MusicXML). Esta primera versión prepara la carga y la vista previa; todavía no reconoce notas automáticamente ni genera MIDI desde imágenes o PDF.

Importante: para reconocer notas en imágenes y PDF hace falta conectar un motor OMR. La aplicación está alojada en GitHub Pages, así que ese procesamiento necesitará un servicio compatible. No se modificará el reproductor actual.
